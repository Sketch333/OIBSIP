- Review the onboarding LinkedIn/resume tutorial and placement-support materials in the provided task document.
- Review every executed notebook and understand the methods and limitations.
- Record a separate end-to-end demo for each task. Start with a static 2-second title card: Syed Aon Muhammad Kazmi | Data Science | [Task Title].
- Demo sequence: objective and dataset → run loading/EDA → show charts → run models and evaluations (or regional/COVID comparisons for Task 2) → explain findings and limitations → demonstrate an example prediction for model tasks.
- Post each demo on LinkedIn, tag Oasis Infobyte and include #oasisinfobyte and #datascience.
- Watch at least two cohort members’ demos and write substantive, specific comments yourself after watching.
- Submit the OIBSIP repository link using the form in your orientation/offer email; follow its batch deadline.
- GitHub publishing, LinkedIn posts, peer comments and form submission are not completed by this project pack.
